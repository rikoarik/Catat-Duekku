# Deploy

## Expo public env

```env
EXPO_PUBLIC_SUPABASE_URL=
EXPO_PUBLIC_SUPABASE_ANON_KEY=
EXPO_PUBLIC_TELEGRAM_BOT_USERNAME=
```

## Supabase secrets

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_WEBHOOK_SECRET=
```

## Setup

1. Buat project Supabase.
2. Jalankan migrations.
3. Aktifkan email auth.
4. Isi Expo env.
5. Buat Telegram bot.
6. Isi Supabase secrets.
7. Deploy Edge Functions.
8. Set webhook Telegram.
9. Jalankan Expo.
10. Jalankan test.
11. Build preview Android/web.
